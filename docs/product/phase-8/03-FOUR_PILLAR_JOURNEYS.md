# 3. Four-pillar user journeys

## Persona: independent learner (Personal workspace)

### PLAN
1. Open Home → see today’s plan snapshot  
2. Adjust Planner / Tasks  
3. Optional: AI planner suggest → accept into tasks (existing resolve flow)

### LEARN
1. From Home “ادامه یادگیری” → Topics or Timer  
2. Practice via Assessment or Tests  
3. Evidence writes mastery / SRS / outbox events

### IMPROVE
1. Reviews due → complete SRS  
2. Mastery/Journey shows unlocked stages from evidence  
3. Analytics + AI coach explain *why* (facts vs narrative)

### ACHIEVE
1. Daily missions complete from real evidence  
2. Claim rewards; cosmetics unlock only from achievement rules  
3. Personal Improvement view shows self vs baseline (not peer shaming)

## Persona: school student (School workspace)

Same pillars; Home adds class assignments/missions from teacher. Leaderboards respect privacy + school settings. Parent sees read-only summaries of child (existing).

## Persona: teacher / school admin

Not four-pillar primary users. Keep Teacher / School Admin portals. Teacher “missions” later map to `QuestDefinition` with proper completion evidence (fix `manual` gap in Phase 10).

## Coherence rule
Every journey step must deep-link into an existing or Phase-9+ screen without opening a disconnected microsite.
